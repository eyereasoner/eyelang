# Example decks

Wide-audience companion explanations for selected runnable examples.

- [Cross-organization data sharing](cross-organization-data-sharing.md) — ODRL/DPV sharing decisions with permit, deny, review, safeguards, and obligations.
- [Explainable EV-depot configuration](explainable-ev-depot-configuration.md) — reversible configuration rules that select a charger, explain blockers, and derive required changes.
- [ODRL policy reasoning](odrl-policy-reasoning.md) — permissions, prohibitions, duties, conflicts, and defaults.
- [Operational incident response](operational-incident-response.md) — topology-aware root-cause, impact, evidence-chain, and safe-mitigation reasoning.
- [SBOM vulnerability response](sbom-vulnerability-response.md) — transitive exposure paths, severity policy, waivers, deployment decisions, and upgrade actions.
- [Scientific evidence graph](scientific-evidence-graph.md) — RDF 1.2 claims, provenance, evidence quality, corroboration, and explicit disagreement.
- [Symbiotic Knowledge Graphs](symbiotic-knowledge-graphs.md) — a real-world RDF → Prolog → RDF heatwave-response loop in which AI proposes, explicit rules govern, people review, and accepted knowledge improves later decisions.
